# 无限画布模型挂载与默认配置控制面板方案

状态：方案、实现与受控发布已完成（2026-10-08）。管理员控制面板已上线，Canvas 静态前端已更新；生产配置仍为空，未通过页面测试写入。管理员登录后可在「AI 模型与路由 → 无限画布配置」配置挂载与默认值。线上 `/api/ready` 仍为 Provider unhealthy 的 503 基线；控制面板/API 已通过线上验收，但真实 Provider 生成、资产历史和积分闭环尚未因此验证。

## 目标与入口

- 在管理员后台「AI 模型与路由」下增加「无限画布配置」页面。
- 按图片、视频、文本、音频四类挂载模型；候选只来自当前已上架且有已审核渠道的规范模型。挂载控制画布可选范围与 Canvas 请求准入，不改变模型上架、价格、渠道或自动路由状态。
- 为每类指定一个已挂载的默认模型；设置画布生图张数、音频声音/格式/语速/指令、系统提示词。用户在画布内仍可临时调整偏好，后台值作为进入画布时的初始值。

## 数据与接口

- 存储于既有 `system_settings` 的 `canvas_model_config`，复用后台 `models.read/models.write` 权限、幂等写入和审计；不新建价格表或 Provider 凭证字段。
- 后台 `GET/PUT /api/admin/canvas/config` 返回候选、已挂载项与默认值；写入时验证模型类型、可用资格和默认项所属关系，失败保持原配置。
- 画布只读 `GET /api/canvas/config`，仅向已登录用户、精确 `https://canvas.koyosim.com` Origin 暴露安全投影。未配置时保持现有模型目录行为，管理员首次保存后按挂载清单过滤。
- 后台关闭挂载或模型下架后，画布下次读取立即移除该模型；已有任务和资产不改写。生产源树候选补丁同步过滤 `/api/canvas/models`，并在 quote/job 写入口拒绝未挂载模型。模型真正能否执行仍由主站 Router、Provider、积分服务判定。

## 验收

1. 只读管理员可看不可保存；无权限和匿名请求被拒绝；写入留审计。
2. 未上架、类型不匹配、未挂载默认项不能保存；刷新后台保持配置。
3. 画布四类选择器仅显示挂载且当前仍可用的模型；新会话呈现平台默认值；本次会话内用户可单独覆盖。
4. 线上路由恢复后，用隔离身份验证模型目录、报价、任务终态、资产/历史与积分扣费或退回；在此之前不标记商业闭环完成。
