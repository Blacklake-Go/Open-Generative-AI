# 个人中心与设置极简重构方案 (Personal Center & Settings Modernization)

> **目标**：彻底告别原本由 11 项侧边栏构成的臃肿后台模式，将「个人中心 / 设置」深度精简为轻盈、现代、聚焦的居中交互浮层（~640px 宽度）。
> **核心原则**：
> 1. 深度复刻参考图（`media_1790809123723.png`）的居中头像上传、极简用户名输入与高对比度操作按钮；
> 2. 严格遵循 Koyosim 主设计系统（`docs/UI_DESIGN_SYSTEM.md`）暗色层级与 Cyan 青色（`#22d3ee`）品牌契约；
> 3. 精准保留用户指定的 4 大核心模块：**创作活跃**、**账户密码设置**、**三方账户绑定与登录**、**删除账户**；
> 4. 彻底删除所有多余且冗杂的杂项设置与重叠 Tab。

## 二、删除的冗余内容清单

| 原有组件 / 标签 | 状态 | 移除理由 |
| :--- | :--- | :--- |
| `MembershipTab` (会员订阅) | 彻底移除 | 全站已有独立的 `/pricing` 页面和专用的 `<SubscriptionModal>` 弹窗，不应塞在设置弹窗里。 |
| `PriceDetailsTab` (价格详情) | 彻底移除 | 定价属于商业中台功能，已在 `/pricing` 和模型中心完整呈现。 |
| `UsageTab` (使用明细) | 彻底移除 | 渲染流水属于任务历史，无需在极简个人设置中展开。 |
| `InvoicesTab` (支付凭证) | 彻底移除 | 财务发票属于独立账单中心。 |
| `WalletTab` (积分详情) | 彻底移除 | 积分和算力有专用充值弹窗 `<RechargeModal>` 与 `/coins` 页面。 |
| `AgentApiKeyTab` (API 密钥) | 彻底移除 | 开发者密钥移至开放平台，不干扰普通创作者体验。 |
| `SettingsTab` (系统通知/画质) | 彻底移除 | 杂项开关全数精简。 |
| 条款/隐私政策 Tab 链接 | 彻底移除 | 底部已有全站页脚链接，不再占用设置弹窗空间。 |
| 资料繁琐字段 | 彻底移除 | 删除 Bio、43国国籍选择、性别、职业代码、风格标签、个人主页等沉重表单，仅保留参考图的**头像**与**用户名**。 |

## 三、落地步骤计划

1. **重构 `components/account/tabs/ProfileTab.js`**：
   - 顶部居中渲染头像上传（复刻参考图微光同心圆与相机图标）；
   - 用户名输入框及提示语规范；
   - 密码设置/修改模块；
   - 手机号、邮箱与社交账号（微信/QQ/抖音/Google/X/TikTok）绑定模块；
   - 底部危险区注销账户；
   - 移除 Bio/Country/Occupation/Style 等历史遗留冗余字段。

2. **重构 `components/account/AccountLayout.js`**：
   - 弹窗外壳收紧为 `max-w-[640px]` 居中卡片，移除 1180px 宽屏侧边栏；
   - 顶部提供 `[ 创作活跃 | 账号设置 ]` 高质感胶囊切换；
   - 右上角保留极简 `X` 关闭按钮；
   - 底部提供退出登录快捷入口。

3. **重构 `app/account/AccountClient.js`**：
   - 仅加载和渲染 `ActivityTab` 与全新的极简 `ProfileTab`；
   - 适配 `normalizeTab`，映射只保留 `activity` 和 `settings`（兼容外部路由与 URL 参数）；
   - 精简依赖。

4. **同步精简 `components/UserDropdownMenu.js`**：
   - 将下拉菜单项精简为：「个人中心 / 设置」、「会员中心」、「算力充值」与「退出登录」；
   - 移除冗余的 6 级旧路由跳转。

5. **本地验证与自动化测试**：
   - 编写与更新针对新简化个人中心与导航跳转的单测；
   - 执行 `npm run release:check`、`npm run format:check`、`npm run build`。

6. **自动部署与线上验证**：
   - 部署至 `43.155.166.90` 生产服务器并测试。
