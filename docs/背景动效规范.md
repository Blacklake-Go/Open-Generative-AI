# KoyoSIM 背景动效规范（AI 空间光影视觉系统）

> **规范版本**：v1.0 (2026-09-29)  
> **视觉对齐**：Google Stitch 真实物理光影与交互点阵标准  
> **适用范围**：全局页面（首页、落地页、Studio 工作台、无限画布、独立工具面板、展示模态框等）  
> **核心原则**：高帧率、硬件加速、零 CPU 开销、零业务侵入、100% 指针穿透安全。

## 1. 视觉架构与图层分级规范

背景动效系统采用 **4 级核心图层体系**，严格自底向上垂直层叠：

```
┌────────────────────────────────────────────────────────────────────────┐
│                        背景动效图层层叠规范                            │
├────────────────────────────────────────────────────────────────────────┤
│ Layer 3 (Z-Index 4):  前景内容操作层 (UI Components / 提示词栏 / 卡片) │
│                       - 必须处于透明或毛玻璃容器内                     │
│                       - 交互元素具备 pointer-events: auto             │
├────────────────────────────────────────────────────────────────────────┤
│ Layer 2 (Z-Index 3):  地平线渐隐过渡层 (Horizon Fade Overlay)          │
│                       - h-64 渐变：from-transparent to-[#050507]        │
│                       - 确保底部操作台、输入框与文字的高清晰度与对比度 │
│                       - pointer-events: none                          │
├────────────────────────────────────────────────────────────────────────┤
│ Layer 1 (Z-Index 1):  动态物理点阵画布 (StitchCanvasGrid 2D Canvas)    │
│                       - 16px 晶格点阵 + 1px 细微圆点                   │
│                       - Perlin 柏林流体噪声微扰动                      │
│                       - 725px 鼠标物理斥力位移场 + 弹簧惯性回弹阻尼    │
│                       - 鼠标周边点阵青蓝与蓝紫双色极光相位变幻         │
│                       - pointer-events: none (严禁拦截任何鼠标事件)    │
├────────────────────────────────────────────────────────────────────────┤
│ Layer 0 (Z-Index 0):  3D 物理流体极光影片 (AuroraVideoLayer)           │
│                       - 2304×1440 20秒无缝循环超清视频                 │
│                       - 硬件级 GPU 视频解码，CPU 与 GPU 绘制计算开销为 0│
│                       - 底层铺设 Obsidian 暗夜空间 (#050507) 径向渐变  │
│                       - pointer-events: none                          │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. 组件 API 与参数定义

系统提供开箱即用的顶层容器组件 `<SpatialBackground />`，位于 `components/spatial` 及 `packages/studio/src/ui/spatial`。

### 3.1 `<SpatialBackground />` Props

| 属性名 | 类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `variant` | `'hero' \| 'studio' \| 'canvas' \| 'minimal'` | `'hero'` | 场景模式：<br>• `'hero'`：全功能极光与点阵，饱和度最高<br>• `'studio'`：工作台模式，微调光影纯度，保障操作区沉浸<br>• `'canvas'`：无限画布模式，点阵适度放大，支持视差位移<br>• `'minimal'`：微光模式，仅弱点阵与微光 |
| `showAurora` | `boolean` | `true` | 是否开启底层流体极光影片（移动端或省电模式自动降级为平滑 CSS 渐变） |
| `showGrid` | `boolean` | `true` | 是否开启物理交互点阵 Canvas |
| `showArc` | `boolean \| null` | `null` | 是否显示天际巨幅弧形光幕（`null` 时在 hero/studio 桌面端自动开启） |
| `showPointer` | `boolean \| null` | `null` | 是否开启桌面端光标追随微光晕 |
| `showNoise` | `boolean` | `true` | 是否开启防 8-bit 色阶断层的微晶噪点层 |
| `isFixed` | `boolean` | `true` | 是否全屏固定（`fixed inset-0`），设为 `false` 则为相对定位容器（`relative w-full h-full`） |
| `parallaxOffset`| `{ x: number, y: number }` | `null` | 无限画布视口偏移坐标，背景将以 `0.06` 的视差系数产生深邃空间立体感 |
| `children` | `React.ReactNode` | `null` | 前景内容节点（将安全渲染于光影层之上） |

### 3.2 子组件独立导入

若无需全套容器，可单独导入子模块：
```jsx
import {
  StitchCanvasGrid, // 物理点阵画布 (可单独放置于任何透明容器中)
  AuroraVideoLayer, // 3D 流体视频层 (含 poster 与 CSS fallback)
  AuroraField,      // 纯 CSS 多频极光光场 (轻量备用)
  AuroraArc,        // 天际弧形光幕
  PointerGlow,      // 鼠标跟随微光
  NoiseOverlay,     // 微噪点图层
} from '@/components/spatial';
```

### 模板 C：无限画布（Infinite Canvas）视差套用

```jsx
import React, { useState } from 'react';
import { SpatialBackground } from '@/components/spatial';

export default function InfiniteCanvasWorkbench() {
  // 无限画布平移坐标
  const [viewportOffset, setViewportOffset] = useState({ x: 0, y: 0 });

  return (
    <div className="relative w-screen h-screen overflow-hidden bg-black select-none">
      {/* 注入带 0.06 视差系数的动态点阵与光场 */}
      <SpatialBackground
        variant="canvas"
        isFixed={true}
        parallaxOffset={viewportOffset}
        showArc={false}
      />

      {/* 画布节点与连线操作层 */}
      <div
        className="absolute inset-0 z-10"
        onPointerMove={(e) => {
          if (e.buttons === 1) {
            setViewportOffset((prev) => ({
              x: prev.x + e.movementX,
              y: prev.y + e.movementY,
            }));
          }
        }}
      >
        {/* Canvas Nodes */}
      </div>
    </div>
  );
}
```

## 5. 核心样式与微交互规范（Stitch Conic 光环）

与该背景搭配的输入框（如 `PromptComposer`）或主推卡片，需遵循 Stitch 原版 4 色极光微光规范：

### 5.1 色彩常数
```css
:root {
  --aurora-purple: #9154e7; /* rgb(145, 84, 231) */
  --aurora-indigo: #6056f0; /* rgb(96, 86, 240) */
  --aurora-teal:   #40d9c6; /* rgb(64, 217, 198) */
  --aurora-blue:   #4285f4; /* rgb(66, 133, 244) */
}
```

### 5.2 输入框聚焦微光标准 CSS
```css
/* 输入框容器 */
.prompt-composer-spatial {
  background-color: rgba(22, 23, 28, 0.65);
  backdrop-filter: blur(24px);
  -webkit-backdrop-filter: blur(24px);
  border: 1px solid rgba(255, 255, 255, 0.08);
  box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.1), 0 8px 32px -8px rgba(0, 0, 0, 0.5);
  transition: border-color 0.25s ease, box-shadow 0.25s ease;
}

/* 获得焦点时的极光呼吸光晕 */
.prompt-composer-spatial:focus-within {
  border-color: rgba(96, 86, 240, 0.48);
  box-shadow: 
    inset 0 1px 0 rgba(255, 255, 255, 0.14),
    0 0 32px -4px rgba(96, 86, 240, 0.35),
    0 0 14px 0 rgba(64, 217, 198, 0.25);
}
```

### 5.3 旋转色锥光环（Conic Aurora Ring）
若需为特权卡片或高亮入口添加原版 360° 流动光环：
```css

  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
```

## 6. 四大避坑红线（Golden Rules）

在套用本动效背景时，**必须严格遵守**以下四大准则：

1. ❌ **严禁使用实心黑底遮挡**：
   - 任何父容器或子工作区组件（如 `StandaloneShell`、`*Studio.jsx`）**不得设置** `bg-base`、`bg-black`、`bg-[#050507]` 或 `bg-gray-950`；
   - 必须统一设置为 `bg-transparent`，让底层的 3D 流体缎带与点阵自然穿透。
2. ❌ **严禁背景图层拦截指针事件**：
   - 无论何时自定义或扩展背景元素，外层容器与 `<canvas>` / `<video>` 必须强制包含 `pointer-events: none`；
   - 前景可点击的操作按钮、输入框、卡片等必须确保拥有正常的可交互状态。
3. ✅ **必须保留地平线渐隐过渡**：
   - 工作台下半部分必须保留 `h-64 bg-gradient-to-b from-transparent to-[#050507]` 的地平线渐隐层，防止流体光浪色彩过亮干扰输入文字的可读性。
4. ✅ **优先使用自托管静态资源**：
   - 引用视频请固定使用 `/branding/videos/spatial-aurora.mp4`，禁止直连海外公共 CDN，确保弱网与国内各运营商环境下的秒开秒播。
